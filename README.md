# True Dragon Ascension and Aatrox update

True Dragon Ascension has been merged into the original `jjk_spells` project and registered with its existing mod bootstrap.

Five Aatrox spells are registered in the same spell registry:

- **The Darkin Blade** — 6-block heavy cleave with a stronger central impact, knockback, and stagger.
- **Infernal Chains** — 12-block target strike, Alex's Caves irradiation (when installed), slow, delayed pull, and a 3-second stun.
- **Umbral Dash** — controlled 5-block dash that damages enemies passed through.
- **World Ender** — 12-second 50% damage state with 20% damage-to-health healing capped at 40 health per hit.
- **Oblivion's Descent** — 1.5-second wind-up and a 10-block crimson impact zone that deals 280 + 10% target max health and knocks enemies away.

All Aatrox effects use crimson spores and soul-fire particles. No spell permanently modifies blocks.
